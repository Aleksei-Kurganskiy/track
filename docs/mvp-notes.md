# MVP Notes

Первая версия `track` должна ответить на три вопроса:

1. Как создаётся задача.
2. Как запускается отсчёт времени.
3. Как в интерфейсе показывается живой прогресс.

Начальный сценарий пользователя:
- создать задачу
- нажать `start`
- видеть таймер с момента запуска
- видеть progress bar, который обновляется в реальном времени
- завершить задачу
