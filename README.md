# track

`track` - это личный трекер задач, в котором важен не только дедлайн, но и живое ощущение движения задачи в работе.

## Идея

В обычных таск-менеджерах задаче часто просто ставится срок выполнения. В `track` основной фокус другой:
- живой progress bar, который обновляется каждую секунду
- отображение времени с момента запуска задачи
- наглядное ощущение текущего прогресса, а не только конечной даты

Цель проекта - сделать инструмент, который показывает, как задача движется прямо сейчас.

## Основная концепция

У каждой задачи должен быть активный жизненный цикл:
- создать задачу
- запустить задачу
- видеть, сколько времени прошло с момента старта
- наблюдать живое изменение прогресса
- быстро понимать текущее состояние задачи

## MVP

Первая версия должна быть максимально простой и полезной.

Минимальный функционал:
- создание задачи
- запуск задачи по кнопке или команде `start`
- отображение elapsed time с момента старта
- живой progress bar с обновлением каждую секунду
- список активных и завершённых задач

## Дальнейшее развитие

Со временем проект может обрасти дополнительными инструментами вокруг задач и личной продуктивности:
- планирование
- история активности
- аналитика по времени
- статусы и сценарии работы с задачами
- дополнительные вспомогательные инструменты

## Ближайший шаг

Сейчас важно собрать самый первый рабочий контур продукта:
- описать сущность задачи
- определить, как запускается отсчёт времени
- определить, как рассчитывается и отображается прогресс
- сделать простой интерфейс или прототип, где это можно увидеть вживую
